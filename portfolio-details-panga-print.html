Project Overview

PangaPrint is a web‑based PDF processing and print‑optimization dashboard built with Django and Bootstrap. It helps users upload PDF files, track job status, and download fixed/optimized print files. The dashboard provides real‑time metrics (total jobs, success/failure counts, and success rate), a table of recent processing jobs, and quick‑action buttons for uploads, printer‑profile management, processing history, and system settings.

The interface is intentionally simple and modern, focusing on clear status indicators, clean typography, and intuitive navigation so users can quickly monitor their print jobs and perform core actions without distraction.

Key Features

Upload and Processing Workflow

The system begins with a simple PDF upload flow, where users select a file and submit it to the processing queue. Once uploaded, each job is tracked with a unique status, and upon successful completion, a downloadable optimized version of the PDF becomes available in the dashboard for easy access and reuse.

Quick‑Action Panel

A dedicated panel of pill‑style buttons gives one‑click access to essential functions: uploading a new PDF, managing printer profiles, viewing processing history, and adjusting system settings. The compact layout keeps core actions visible and reachable directly from the dashboard, improving user efficiency.

Modern Responsive UI

The interface uses a clean, mobile‑first Bootstrap layout with consistent spacing, subtle shadows, and rounded corners to create a modern and professional look. Empty‑state messages guide users when no jobs are present, and the modular CSS structure makes it easy to extend the design to light or dark themes in the future.

Recent Jobs Table

A responsive table lists recent processing jobs, showing filename, status badge, page count, and creation time for each entry. Status badges dynamically update their color based on job state (success, warning, or error), and completed jobs include a download button for the fixed PDF while failed jobs show an error label with the message in a tooltip.
